# テトリス・レース

無限に落ちていくテトリスゲーム。底が抜けた後、障害物を避けるか、破壊しながら深さを目指すアクションパズルゲーム。

## バージョン
v1.0.7

## 概要

テトリスの底が抜ける仕掛けから始まる、4段階のプログレッシブゲーム。
表向きは通常のテトリスだが、底を抜くことで落下型ゲームへと変貌し、最終的には障害物を破壊しながら深く潜るスリリングなゲームへと進化する。

---

## ゲームフロー

ゲームは以下の4つのフェーズで構成され、シームレスに移行する。

### Phase 1: 通常のテトリス (The Disguise)
* **状態:** 標準的なテトリスプレイ
* **落下速度:** 遅い (gravity 0.5)
* **目標:** ボトムライン（最下行）を完成させる
* **進行:** ボトムラインをクリアすると底が物理的に抜け落ちる → **Phase 2へ移行**

### Phase 2: そこが抜けた通常のテトリス
* **開始:** ボトムラインがクリアされた直後
* **状態:** ボトムラインが消えて、底に穴が開いた状態
* **落下速度:** 遅い (gravity 0.5)
* **重要:** 上には積むことができる（テトリスを続けられる）
* **穴の活用:** 穴を通すピースが落ちていく
* **進行:** ピースが穴を通過 → **Phase 3へ移行**

### Phase 3: 無限落下 (Free Fall with Obstacles)
* **開始:** ピースが穴を通過した時点
* **基本ルール:** Phase 1・2と全く同じ（底がないだけ）
* **落下速度**
  - 0～10秒：通常速度（gravity 1）
  - 10秒以上：加速（gravity 2）
* **障害物**
  - 灰色のブロック（テトリスと同じ）として無限に配置
  - 難易度は時間経過で段階的に上昇
  - ピースと同じように積み上げられる
  - **横一列揃えると消える**（通常のテトリスと同じ）
* **ゲームプレイ**
  - ピースをボードに置く（テトリスと全く同じ）
  - 行を完成させて消す（障害物も含めて）
  - ゲームオーバー：新しいピースが配置できなくなった時
* **戦略**
  - 障害物を避けて落ちる（深さスコア狙い）
  - 障害物を積み上げて行をクリア（破壊戦略）
* **進行:** 20秒経過 → **Phase 4へ移行**

### Phase 4: ランダムレース (Endless Drift - Max Difficulty)
* **開始:** Phase 3で20秒経過した時点
* **状態:** 完全なエンドレスモード。ゴールは存在しない
* **落下速度:** 高速（gravity 3）
* **障害物:** 最高難易度のランダムパターン
* **スコア:** ゲームオーバーまで点数が増え続ける

## 操作系

### キーボード操作
* **← / →**: ピース左右移動
* **↓**: ピース下降（加速落下）
* **↑**: ピース右回転（時計回り）
* **Shift + ↑**: ピース左回転（反時計回り）
* **Space**: ハードドロップ（底まで一気に落下）

### 画面UI（マウス/タッチ）
画面フッターに5つのボタンをレトロデザインで配置
1. **[←]**: 左移動
2. **[⟲]**: 左回転
3. **[↓]**: 下降
4. **[⟳]**: 右回転
5. **[→]**: 右移動

## 障害物システム

### 障害物の仕様
* **表示:** 灰色（#808080）のブロック
* **挙動:** テトリスの通常ブロックと完全に同じ
* **配置:** Phase 3開始時から段階的に難易度が上昇
* **クリア方法:** 障害物を含めて横一列を完全に埋める
  - 横一列完成で自動的に行がクリア
  - 上のブロックが下に落ちてくる（テトリスと同じ）

### 障害物パターン（Phase 3）

#### 1. Straight（直線）
- 中央に立てかけるブロック
- 難易度によってサイズ変更（H: 2-4）

#### 2. Chicane（シケイン）
- 側面に配置される障害
- 左右どちらかにランダム出現
- 難易度によってサイズ変更

#### 3. S-Curve（S字カーブ）
- 複合的な障害物パターン
- 難易度でブロック数が増加
- 難易度0: 2ブロック、難易度1: 3ブロック、難易度2: 4ブロック

#### 4. Narrow Gate（狭い門）
- 両側から狭まる門状の障害
- 難易度が上がると門幅が狭くなる
  - 難易度0: 門幅4ブロック
  - 難易度1: 門幅3ブロック
  - 難易度2: 門幅2ブロック（超難関）

### 戦略

**避ける戦略**
- 左右移動で障害物を回避
- 深さスコアを稼ぐ

**破壊戦略**
- 障害物を含めて横一列を完成させる
- 行クリアで障害物を消去
- 深い位置での戦闘で高スコア獲得

## スコアシステム

### スコア構成
```
総スコア = 行クリアスコア + 深度スコア + 時間ボーナス
```

- **行クリアスコア:** 1行クリア = 100ポイント
- **深度スコア:** Phase 3以降での落下距離 × 10
- **時間ボーナス:** 生存時間（秒）× 5ポイント

### 深度表示
- ゲーム画面に「深度：XXXm」として表示
- Phase 3でピースが落ちるたびに増加

## デザイン仕様

### ビジュアルスタイル
* **Retro Tetris:** 8bit風のドット絵、またはモノクロ液晶風（緑がかったグレー等）のカラーパレットを採用。
* **Contrast:** レースモード突入後もレトロな見た目は維持しつつ、流れる背景や集中線エフェクトでスピード感を表現する。

## 5. ステージ生成アルゴリズム (Phase 4)

Phase 4では、以下のセグメントをランダムに組み合わせて無限のコースを生成する。

1.  **Straight (直線):** 加速区間。時折、中央にデブリ（1ブロック障害物）が配置される。
2.  **Chicane (シケイン):** 左→右、または右→左へと素早い切り返しを強いるクランク状の壁。
3.  **S-Curve (S字):** 緩やかに蛇行する壁。適切なタイミングでの回転制御が必要。
4.  **Narrow Gate (狭門):** 1列分しか隙間がない壁。I字テミノを縦にしないと通過できない。

---

## 6. 技術的要件 (Technical Requirements)

* **Responsive View:**
    * デバイスの解像度に関わらず、「上部にゲーム画面、下部にコントローラー」のレイアウトを維持する。
    * PCブラウザ等の横長画面では、中央にモバイル比率のゲーム機（筐体）があるような枠を表示し、その中で画面とコントローラーを描画する（余白は背景で埋める）。
* **Score:** 従来のライン消去点に加え、「深度ポイント（到達距離）」と「生存時間ポイント」をメインのスコア源とする。
* **Asset:** レトロ風のSE（回転音、落下音、衝突音）と、Phase切り替え時のBGM変化。
