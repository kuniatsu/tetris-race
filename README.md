# Project: 深さ無制限Tetris

## 1. 概要 (Overview)
表向きはレトロなビジュアルの古典的「テトリス」だが、特定の条件を満たすことで「落下型レースゲーム」へと変貌するアクションパズルゲーム。
プレイヤーはブロックを消すことではなく、「障害物を避けてより深く潜ること」を目的とする。

**コンセプト:**
* **Genre:** レトロスタイル・パズル / エンドレス落下レーシング
* **Platform:** Web / Mobile (Responsive), PC
* **Target:** 意外性を楽しみたいゲーマー、高難易度アクション好き
* **Key Experience:** 「なぜレースゲーム？」という疑問からの、底が抜けた瞬間の驚きと、加速する落下の疾走感。

---

## 2. ゲームフロー (Game Flow)

ゲームは以下の4つのフェーズで構成され、シームレスに移行する。

### Phase 1: 偽装テトリス (The Disguise)
* **状態:** 通常のテトリス。
* **Visual:** ゲームボーイ時代を彷彿とさせるレトロなドット絵と色調。
* **UI表示:** ヘッダーに「**これはレースゲームです**」という謎のメッセージを常時表示。
* **クリア条件:** 最下段（底のレコード）を含むラインを消去すると、底が物理的に抜け落ちる。

### Phase 2: 自由落下 (Free Fall)
* **開始:** 底が抜けた直後。
* **状態:** テミノ（ブロック）が無限の空間を落下し始める。
* **環境:** 最初の1秒間はフリーフォール。その後、無造作なブロック（障害物）が出現し始める。
* **戦略:** ラインを消すことより、隙間を縫ってさらに下へ落ちることを優先する。

### Phase 3: 加速と覚醒 (Acceleration)
* **開始:** 落下開始から10秒経過。
* **状態:** 重力加速度が増加し、物理演算（空気抵抗）が適用され始める。
* **環境:** 障害物の配置が徐々に「コース」らしくなり始める。

### Phase 4: ランダムレース (Endless Drift)
* **開始:** 加速状態が安定した後（Phase 3移行から一定時間後、または深度到達後）。
* **状態:** 完全なエンドレスモード。ゴールは存在せず、ゲームオーバーまで点数が増え続ける。
* **環境:**
    * **マップ生成:** S字カーブ、シケイン、障害物がランダムかつ無限に生成され続ける。
    * **難易度:** 深度が増すにつれて落下速度とコースの難易度が上昇する。

## 3. コアメカニクス仕様 (Core Mechanics)

### 3.1 操作系 (Input & Controls)
**PC・スマホ問わず、画面フッター領域にレトロな物理ボタンUIを常時表示する。**

#### 画面UI (On-Screen Controller)
以下の5つのボタンをフッターに配置し、タップ/クリックで操作可能とする。
配置順（左から右）:
1.  **[左]**: 左移動
2.  **[反時計回り]**: 左回転
3.  **[下]**: ソフトドロップ / 加速
4.  **[時計回り]**: 右回転
5.  **[右]**: 右移動

#### キーボード操作 (Keyboard Support)
PC等の物理キーボードがある環境では、画面UIと並行して以下のキー操作を受け付ける。
（キー操作時も、画面上のボタンが連動して押下されるアニメーションを入れると良い）

* **← / →**: 左右移動
* **↓**: ソフトドロップ / 加速
* **↑**: 右回転（時計回り）
* **Shift + ↑**: 左回転（反時計回り）
* **Space**: ハードドロップ（Phase 3以降はブースト、または無効化）

### 3.2 空気抵抗システム (Aerodynamics) - Phase 3以降
落下の速度制御をテミノの「向き」で行う。

* **縦向き (I字縦など):** 空気抵抗「小」。**加速**する。
* **横向き (I字横など):** 空気抵抗「大」。**減速（エアブレーキ）**がかかるが、衝突判定が広がる。

### 3.3 即死ルール (Sudden Death) - Phase 3以降
* Phase 3以降は、障害物に接触（Conflict）した瞬間に位置が確定（Lock）される。
* 通常テトリスにある「接地後の猶予時間（遊び）」は排除される。

## 4. デザイン仕様 (Design Specs)

### ビジュアルスタイル
* **Retro Tetris:** 8bit風のドット絵、またはモノクロ液晶風（緑がかったグレー等）のカラーパレットを採用。
* **Contrast:** レースモード突入後もレトロな見た目は維持しつつ、流れる背景や集中線エフェクトでスピード感を表現する。

---

## 5. ステージ生成アルゴリズム (Phase 4)

Phase 4では、以下のセグメントをランダムに組み合わせて無限のコースを生成する。

1.  **Straight (直線):** 加速区間。時折、中央にデブリ（1ブロック障害物）が配置される。
2.  **Chicane (シケイン):** 左→右、または右→左へと素早い切り返しを強いるクランク状の壁。
3.  **S-Curve (S字):** 緩やかに蛇行する壁。適切なタイミングでの回転制御が必要。
4.  **Narrow Gate (狭門):** 1列分しか隙間がない壁。I字テミノを縦にしないと通過できない。

---

## 6. 技術的要件 (Technical Requirements)

* **Responsive View:**
    * デバイスの解像度に関わらず、「上部にゲーム画面、下部にコントローラー」のレイアウトを維持する。
    * PCブラウザ等の横長画面では、中央にモバイル比率のゲーム機（筐体）があるような枠を表示し、その中で画面とコントローラーを描画する（余白は背景で埋める）。
* **Score:** 従来のライン消去点に加え、「深度ポイント（到達距離）」と「生存時間ポイント」をメインのスコア源とする。
* **Asset:** レトロ風のSE（回転音、落下音、衝突音）と、Phase切り替え時のBGM変化。
